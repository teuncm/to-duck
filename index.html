      Keyboard shortcuts

      Enter
      Add a to-duck
      Down
      Add box, then each to-duck. After the last to-duck, clear the selection
      Up
      Previous to-duck, then the add box. From the add box, clear the selection
      Left
      From Enter, type in the add box. On a to-duck, focus its checkbox
      Right
      From the add box, focus Enter. On a to-duck, focus delete
      Enter or Space
      Complete the selected to-duck
      C
      Complete the top to-duck
      D
      Delete the selected to-duck. Unavailable in zen mode
      Ctrl+E
      Export
      Ctrl+I
      Import
      Ctrl+K Z
      Toggle zen mode
      Escape
      Leave the add box, exit zen mode, or close settings
